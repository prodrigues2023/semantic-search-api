Semantic Search API / console

hybrid ranking · one Postgres

Reciprocal Rank Fusion combines a lexical leg (tsvector / ts_rank_cd) and a semantic leg (pgvector cosine) into one ranked list — rank-based, not score-based, because BM25 and cosine live on incomparable scales. The embedder is a deterministic offline stub, not a real model; see the README.
